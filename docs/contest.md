# 공모전 요강 요약

> 출처: 요약 노션 페이지(인스타그램 경유) 캡처. **공식 홈페이지 요강 원문으로 재확인 필요** (기획서 양식·심사 기준).

## 한눈에 보기
- 주최: 현대자동차·기아 — 차량용 앱 개발 공모전
- 총상금 **5,100만 원**, **10개 팀** 수상
- **Pleos Playground 공개 API**를 활용한 차량용 앱 아이디어 제안 또는 직접 개발
- 참가 대상: 대학(원)생, 소프트웨어 개발자 / 개인 또는 **최대 5인 팀**
- **기획서 필수**, 데모 영상·구현물은 선택 (아이디어 특별상 있음)
- 수상작은 2027년 2월 현대차그룹 행사에서 전시·시상, **실제 차량 서비스 출시 가능성 검토**

## 공모 분야
- 차량 내 엔터테인먼트
- 운전자 건강·생활 관리
- 안전 운전
- 가족·동승자 편의 서비스

## 개발 플랫폼
- **Pleos Playground**: 현대차그룹 차량용 앱 개발 플랫폼
- 실제 차량 없이 개발·테스트 가능한 환경, SDK·API 문서·샘플 코드 제공
- 2025년 개발자 콘퍼런스 'Pleos 25'에서 공개

## 신청 방법
1. Pleos Playground에서 공개 API·개발 도구 확인 → 아이디어 결정
2. 서비스 기획서 작성 (필수), 데모 영상·구현물 (선택)
3. 공식 홈페이지 신청 또는 이메일 제출: appdevchallenge@hyundai-partners.com
4. 11월 서류 심사 → 통과 시 12월 앱 시연 평가 준비
