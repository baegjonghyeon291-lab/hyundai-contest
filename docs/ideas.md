# 아이디어 후보

> 메인 주제는 아직 미정. 사용자가 직접 결정. (기능 전체 목록: docs/car-features.md)

## 후보 (보류·보조)

### ⭐ 차량용 데이터 블랙박스 — 후보 (메인 아님)
"영상 대신 숫자로 남기는 블랙박스". 억울함 방지.
- **사고 과실 다툼 대응**: 최근 1~2분 차량 상태를 링버퍼로 상시 기록, "사고 났어"(음성)·급정거·버튼 시 전후 구간 저장 → "깜빡이 3초 전 켬, 브레이크 0.8초 반응, 42km/h" 리포트
- **남이 내 차 탈 때 기록**: 발레·정비·대리·가족 공유 시 맡긴 동안 주행 거리·시간·경로·급제동, 바뀐 시트·공조 설정 리포트
- **(선택) 뒷좌석 벨트 안내 기록**: 좌석별 탑승·벨트 감지 → 미착용 좌석 안내, 택시·카풀은 "안내했음" 기록
- 데이터: 방향지시등, 브레이크, 속도(위치), 기어, 전조등, 와이퍼, 시트, 공조, 주행 기록, 음성 인식
- 저장: 숫자만 기록 → 1시간 약 2MB. 주행 일지 30일, 사고 구간은 수동 삭제 전까지 보관. QR로 휴대폰에 리포트 전달, 기본은 차 밖으로 안 나감
- 사업성: 보험사(과실 산정·UBI), 렌터카·카셰어링·택시

## 검토 후 제외
- 무단횡단 사고 예방 — 카메라·레이더 데이터가 외부 앱에 미제공이라 "갑자기 튀어나오는" 상황 대응 불가 (AEB 영역)
- 전기차 관련 — 사용자 요청으로 제외

## 그 밖의 아이디어 풀
| 이름 | 한 줄 |
|---|---|
| 쉼표 (졸음 케어) | 연속 주행·지시등 없는 차선 변경으로 피로 추정 → 단계별 깨우기 → 휴게소 |
| 에어컨 냄새 예방 | 도착 전 에어컨 끄고 송풍 건조 |
| 하차 점검 | P·벨트 해제·문 열림 시 열린 창문·켜진 등 알림/자동 처리 |
| 동승자 자동 맞춤 | 좌석별 탑승자에 맞춰 공조·열선·통풍, 음성으로 자리별 조절 |
| 동승석 내비 도우미 | 동승자가 경로·휴게소 검색, 운전자에게 음성 전달 |
| 펫 케어 모드 | 공조 유지 + 밖에서 보이는 안내 화면 |
| 멀미 케어 | 조향·급제동 패턴으로 멀미 위험 → 뒷좌석 환기·바람 |
| 택시 경로 인증 | 운행 경로·시간을 추천 경로와 비교해 우회 시비 방지 |
