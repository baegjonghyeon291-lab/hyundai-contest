# Pleos 차량 기능 전체 목록 + 새 기능 아이디어

> 출처: Vehicle SDK 2.3.2 실제 코드(AAR)에서 추출 + Pleos 문서 + 에뮬레이터 확인 (2026-10-24)
> 읽기 = 앱이 값을 볼 수 있음 / 제어 = 앱이 차를 직접 움직일 수 있음
> 실제 차종에 따라 일부 기능은 미지원일 수 있음 (앱에서 지원 여부 확인 API로 체크)

## 1. 앱이 쓸 수 있는 차량 기능 (Vehicle SDK)

| 분류 | 읽기 | 제어 |
|---|---|---|
| **공조(HVAC)** | 전원, 설정 온도, 실내 현재 온도, 풍량, 바람 방향, 에어컨, 최대 냉방, 오토, 듀얼, 내·외기 순환, 공기청정, 성에 제거 | **전부 제어 가능** |
| **시트** | 탑승 여부(좌석별), 안전벨트 착용, 등받이 각도, 앞뒤 위치, 높이, 쿠션 기울기, 허리 지지, 헤드레스트, 시트 열선·통풍 상태 | 시트 열선, 시트 통풍 |
| **핸들** | 조향 각도, 열선 상태 | 핸들 열선 |
| **창문** | 창문 열림 위치, 창문 잠금, 블라인드, 스마트 글라스(유리 투명도) | 창문 열기/닫기, 창문 잠금, 스마트 글라스 투명도 |
| **문** | 잠금 상태, 열림 위치, 글로브박스 잠금 | 문 잠금/해제, 문 열기/닫기, 글로브박스 잠금 |
| **조명** | 무드등(색·밝기), 실내등, 독서등, 전조등(상향·하향), 안개등, 미등 | **무드등 색·밝기**, 실내등, 독서등, 전조등, 안개등, 미등 |
| **사이드미러** | 열선 상태 | 미러 열선 |
| **와이퍼** | 작동 상태, 스위치 | 와이퍼 작동 |
| **주행** | 기어(P/R/N/D), 브레이크 페달, 주행 모드, 크루즈 컨트롤 상태·설정 속도, 방향지시등 | — |
| **주행 기록** | 총 주행거리, 남은 주행 가능 거리, 이번 주행 거리·시간, 누적 주행 거리·시간, 충전/주유 후 거리·시간 | — |
| **전기차 배터리** | 배터리 잔량(%), 용량, 충전 상태, 충전 전류, 전비(순간·누적·충전 후) | 충전 시작/중지, 충전 목표 %, 충전 전류 제한, 충전구 열기 |
| **연료** | 연료 잔량, 연비(순간·누적) | — |
| **안전·점검** | 경고등 정보, 엔진오일·브레이크액·변속기오일 상태, 타이어 공기압, 저압 경고 | — |
| **차량 정보** | 차대번호(VIN), 차종 정보, 지원 기능 목록 | — |
| **하이패스** | 안내 음성 볼륨 | 안내 음성 볼륨 |

## 2. 그 외 SDK

| SDK | 할 수 있는 것 |
|---|---|
| NaviHelper | 경로 안내 제어, 목적지·경유지, 내비 정보 |
| FusedLocation | 차량 위치 (속도 계산 가능) |
| SpeechToText | 음성 인식 (말로 명령) |
| TextToSpeech | 음성 안내 (차가 말함) |

## 3. 에뮬레이터 기본 탑재 앱 (이미 있는 것 → 우리 앱과 겹치면 안 됨)
- 차량 설정(충전 관리, 디스플레이, 사운드, 프로필 등), 내비게이션, 전화, 미디어, 카메라
- **Gleo AI** (현대차 AI 음성 비서), Connect Mirroring (휴대폰 미러링)
- 하단 바: 공조 온도·풍량, 시트 열선, 핸들 열선, 성에 제거

## 4. 추천 새 기능 (차량 데이터 없이는 불가능한 것 위주)

| # | 기능 | 분야 | 무엇을 하나 | 쓰는 차량 기능 |
|---|---|---|---|---|
| 1 | **뒷좌석 아이 남김 방지** | 가족 | 주차(P)·문 잠금 후에도 뒷좌석 탑승 감지되면 경고 + 에어컨 자동 가동 + 창문 살짝 | 시트 탑승, 기어, 문, 공조, 창문 |
| 2 | **멀미 케어** | 동승자 | 핸들 각도 변화·잦은 브레이크로 멀미 위험 감지 → 뒷좌석 바람 방향·외기 전환·창문 환기·음성 안내 | 조향 각도, 브레이크, 공조, 창문, TTS |
| 3 | **충전 대기 라운지** | 엔터·생활 | 충전 시작되면 자동 휴식 모드: 무드등, 스마트 글라스 어둡게, 시트·공조 맞춤, 목표 %까지 남은 시간 표시 | EV 충전 상태, 조명, 스마트 글라스, 공조, 시트 |
| 4 | **차박·캠핑 모드** | 엔터·생활 | 밤새 배터리 소모를 계산해 공조 유지, 무드등, 창문 틈 환기, 배터리 하한선에서 자동 정지 | EV 배터리, 공조, 조명, 창문 |
| 5 | **쉼표 (졸음 케어)** | 안전 | 연속 주행 시간·방향지시등 없는 차선 변경으로 피로 추정 → 단계별 깨우기 → 휴게소 안내 | 주행 기록, 방향지시등, 공조, 창문, 조명, 음성, 내비 |
| 6 | **펫 케어 모드** | 가족 | 반려동물을 두고 내릴 때 온도 유지, 창문 틈, 문 잠금, 화면에 안내 | 공조, 창문, 문, 배터리 |
| 7 | **동승자 자동 맞춤** | 동승자 | 누가 어느 자리에 탔는지 감지해 그 자리 온도·열선·통풍 자동 세팅 | 시트 탑승, 시트 열선·통풍, 듀얼 공조 |
| 8 | **비 오는 날 안전 모드** | 안전 | 와이퍼 작동 감지 → 전조등·성에 제거·내기 순환 자동, 음성으로 감속 안내 | 와이퍼, 조명, 공조, TTS |
| 9 | **차 안 업무·휴식 공간** | 생활 | 정차 중 "회의 모드": 스마트 글라스 불투명, 무드등, 조용한 공조, 시트 각도 확인 | 기어, 스마트 글라스, 조명, 공조, 시트 |
| 10 | **차량 건강 리포트** | 생활 | 타이어 공기압·오일·경고등을 매주 정리, 이상 시 정비 예약 안내 | 타이어, 안전·점검, 주행 기록 |
| 11 | **초보 운전 코치** | 안전 | 방향지시등 사용률, 급제동, 핸들 조작을 점수화해 주행 후 피드백 | 방향지시등, 브레이크, 조향 각도, 주행 기록 |
| 12 | **에코 드라이빙 게임** | 엔터 | 전비·연비를 실시간 게임처럼 점수화, 가족·친구 랭킹 | 전비/연비, 주행 기록, 위치 |

### 피해야 할 것
- 2025 대상작 '창밖동화'(위치 + AI 동화)와 비슷한 것
- 기본 탑재 앱(내비, 미디어, Gleo AI 음성비서)과 겹치는 것
- 휴대폰으로도 똑같이 되는 것 (심사 기준 '차량특화성')
